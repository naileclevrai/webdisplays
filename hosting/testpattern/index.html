WebDisplays Test Pattern

Modèle broadcast pour murs LED, alignement multi-écrans et calibration scène Theatrical.

  • Barres SMPTE (7 couleurs) à gauche
  • Rampe de luminosité + damier central
  • Ligne de balayage animée (4 s)
  • Réticule + cercle de centrage
  • Zones safe 90% / 80%

Paramètres URL

Ajoutez ces query strings à l’URL hébergée :

  • ?role=MASTER ou SLAVE
  • &res=1920x1080
  • &blocks=4x3
  • &offset=2,0
  • &ui=0 — masque ce panneau
  • &label=0 — masque le texte central
